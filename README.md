# JackLiu00331.github.io
## 个人网站 / Personal Website

这是一个现代化的个人作品集网站，展示我的技能、经验和项目。

### 功能特性 / Features
- **响应式设计** - 适配各种设备尺寸
- **现代化UI** - 采用毛玻璃效果和渐变设计
- **流畅动画** - 页面加载和交互动画效果
- **技能展示** - 前端和后端技术栈展示
- **项目作品集** - 个人项目展示
- **联系方式** - 社交媒体和简历下载

### 技术栈 / Tech Stack
- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript (ES6+)
- 响应式设计

### 设计改进 / Design Improvements

1. **视觉层次优化**
   - 添加渐变背景和毛玻璃效果

### 使用方法 / Usage
1. 克隆仓库到本地
2. 在浏览器中打开 `index.html`
3. 或部署到GitHub Pages等静态网站托管服务
